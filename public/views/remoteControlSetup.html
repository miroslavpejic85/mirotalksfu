3 Check it works

Close the dialog with OK. The status at the bottom of the main RustDesk window should show Ready.

It doesn't say Ready?
  • Check your internet connection, then reopen RustDesk.
  • Make sure the ID server and key were pasted completely, with no extra spaces.
  • Ask the administrator to confirm the server is running.
The ID is not found during a session?
  • Both people must use this same server. Compare the ID server in both RustDesk apps.
  • The one-time password changes. Share the current one shown in RustDesk.
